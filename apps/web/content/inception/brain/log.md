# Log — the living memory

> This is what turns a chatbot into a synthetic *self*: a memory that feeds forward so the agent doesn't restart from zero every time. **It works in two modes depending on your path** — keep whichever sections you use:
> - **Operator path → a ledger.** Four kinds of entry: **check-ins**, **decisions**, **open items**, **retros**. (Sections below.)
> - **Companion path → a witness journal.** Gentler and narrative: what you explored, growth witnessed, resistance met, values shifting, seasons turning. (Section at the bottom.) Keep it light; the agent maintains it for you.
>
> Either way, keep it lean — a trail, not a diary.
>
> **Who writes here?**
> - **Maker build (Cowork / Cursor / Claude):** your agent appends entries itself when you say "save this" (Companion path: it offers, gently).
> - **No-code build (Gemini):** *you* append — paste the entry the agent hands you. Because the Gem reads this doc live (it's a knowledge file), next session it remembers. The few minutes of pasting **is** the compounding.
>
> Newest entries on top within each section. Date everything (YYYY-MM-DD).

- **Revisit:** [[when / what would tell you if it paid off.]]

## Witness journal  *(Companion path)*
*Gentle, narrative entries from `/attune`, `/reflect`, `/discern`, `/synthesize`, and `/witness`. Not a task record — a record of your becoming: what was present, what shifted, what you're sitting with, how the season is turning. The agent keeps this for you, a few lines at a time. Newest on top.*

### [[YYYY-MM-DD]]
- **Present:** [[what was alive — a feeling, a question, a season.]]
- **Explored:** [[what you reflected on or discerned together; any resistance or polarity met.]]
- **Witnessed / growing:** [[an edge that softened, a value clarifying, growth seen — including rest and play.]]
- **Carrying forward:** [[a question to sit with, a small embodied practice, nothing at all.]]
